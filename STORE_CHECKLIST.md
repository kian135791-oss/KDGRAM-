# Store Release Checklist

## Google Play
- [ ] Create/verify Play Console developer account
- [ ] Final Android applicationId: `com.kdgram.app`
- [ ] Configure signing / EAS credentials
- [ ] Build signed `.aab`
- [ ] Store icon, screenshots, feature graphic
- [ ] Privacy policy URL
- [ ] Data Safety form
- [ ] Content rating
- [ ] Closed test if applicable to the developer account
- [ ] Production rollout

## Apple App Store
- [ ] Apple Developer Program account
- [ ] Register Bundle ID `com.kdgram.app`
- [ ] Configure certificates/profiles or EAS credentials
- [ ] Create App Store Connect app record
- [ ] Build signed iOS archive
- [ ] Screenshots for required device sizes
- [ ] App Privacy details
- [ ] Age rating
- [ ] Privacy policy URL
- [ ] TestFlight QA
- [ ] Submit for App Review

## Legal / Trust
- [ ] Terms of Service
- [ ] Privacy Policy
- [ ] Community Guidelines
- [ ] Copyright/report process
- [ ] Account deletion flow
- [ ] Data export/deletion policy
- [ ] Abuse/spam reporting
